# 📚 Book Finder

A React-based web application that helps users search and discover books quickly and easily.

## 🚀 Live Demo

https://recipe-finder-six-inky.vercel.app

## ✨ Features

- Search books by title
- Clean and responsive UI
- Fast search experience
- API integration
- Mobile-friendly design

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Vercel

## 📂 Installation

1. Clone the repository
git clone <repository-url>

2. Navigate to the project folder
cd book-finder


3. Install dependencies
npm install

4. Start the development server
npm run dev
